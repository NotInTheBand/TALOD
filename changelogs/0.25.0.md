# TALOD 0.25.0 — 2026-10-09

Changes since 0.24.0.

### Added

- **Changelog page.** `/talod changelog` (or Main menu → Changelog) shows what changed in every version, newest
  first. "Copy text" turns a version's notes into plain text you can copy into a post or a message.
  `/talod changelog 0.24.0` opens one version.

### Changed

- **The update notice now hears about new versions from every TALOD player on your realm**, not only your guild
  and group. It uses a hidden channel that never shows in your chat windows, and the notes are signed, so nobody
  can fake an update notice. The window opens as soon as a newer version is known and at every login after that
  until you update (never in combat). `/talod version status` shows what the check sees; turning the setting off
  leaves the channel.

Needs a game restart (new files).
